layout: post
title: "Prefer Code over Prompts"
---

For most tasks, even one-offs, it is more efficient and effective to prompt the LLM to generate the code required to accomplish a task, rather than prompting it to do the task. 

Code can be reviewed and easily adjusted. Prompts enter black boxes. Code can be run locally without sending data to the operators of the LLM. Code does not require MCPs to have already been created.
